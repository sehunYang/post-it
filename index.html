Android 폰에 위젯 설치하기 카메라로 QR을 찍으면 끝
  1. 폰 카메라로 왼쪽 QR을 찍어 설치 페이지를 엽니다.
  2. APK 내려받기를 누르고, 내려받은 파일을 열어 설치합니다. "이 출처의 앱 설치 허용"을 한 번 켜 주면 됩니다.
  3. 앱을 열고 지금 이 Google 계정으로 로그인합니다.
  4. 앱 안의 홈 화면에 위젯 추가를 누릅니다.

QR이 안 찍히면 폰 브라우저에 shy.ai.kr/post-it/install/ 을 입력하세요.

Windows 바탕화면 위젯 설치하기 고정한 글을 화면 구석에 띄워 두고 클릭 한 번으로 복사
Windows 위젯 내려받기
  1. 내려받은 post-it-desktop-setup.exe 를 엽니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
  2. 위젯의 Google 계정으로 로그인을 누르고, 브라우저에서 지금 이 계정으로 로그인합니다.
  3. 평소에는 반투명하게 비켜 있다가 마우스를 올리면 또렷해집니다. 컴퓨터를 켜면 저절로 뜹니다.
  4. 끄고 켜기는 작업 표시줄 오른쪽의 Post-it 트레이 아이콘을 누르면 됩니다.
